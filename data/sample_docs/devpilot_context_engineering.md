# DevPilot 上下文工程说明

## 上下文预算

DevPilot 为模型输入设置 6000 token 的保守总预算，为系统指令、RAG 证据和工具结果预留空间。最近对话窗口默认最多使用 2800 token，滚动摘要最多使用 900 token，单条历史消息最多使用 900 token。

## 滑动窗口与截断

系统从最新消息向前选择历史记录，超出窗口的旧消息不直接发送给 Specialist。单条超长消息保留开头和结尾，并插入明确的截断标识，避免静默丢失关键信息。

## 滚动摘要

离开窗口的消息会被压缩到滚动摘要中。摘要保留涉及的服务、用户较早的问题和关键答复片段，并受独立 token 上限约束。会话的规范服务名与当前主题作为结构化字段单独保存，不依赖自然语言摘要。

## 会话隔离

每个会话拥有独立的消息窗口、摘要、服务实体和上下文指纹。同一用户可以创建多个会话，不同用户不能读取或继续对方的会话。当前 user_id 是本地逻辑身份；生产部署仍需接入可信登录和 JWT/RBAC。

## 知识库更新

上传文档后会解析、分块、生成向量并写入 Qdrant，同时在 MySQL 保存文档和块元数据。同一 source_uri 的新内容会更新原文档并增加版本号；相同校验值会跳过重复索引。

知识库页面支持新增、选择已有文档更新、显示版本号、索引状态和知识块数量。
